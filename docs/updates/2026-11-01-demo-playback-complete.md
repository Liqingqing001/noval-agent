# 修复演示正文回放截断

## 原因

演示助手把示例第一章转成可读文字后，使用 `slice(0, 1200)` 截取回放内容。进度以截取后的文本长度判断，因此界面虽然显示回放完成，实际只显示前 1200 个字符，还可能在句子中间结束。

## 修复

- 回放改为完整第一章，不再限制为前 1200 个字符；示例章节正文及其段落边界均保留。
- 显示章节标题、已回放字符数和总字符数，结束后明确提示「本章全文回放结束」。
- 默认使用可滚动的文本区域，并提供「展开全文 / 收起全文」，避免长篇回放挤占整个对话面板；仅改变显示方式，不删除任何回放内容。
- 正文解析按内容缓存，回放到末尾后清理定时器，再次点击演示按钮可以从头回放。
- 回放仍是已有示例文字，不调用模型、不消耗 API、不覆盖访客编辑。真实 AI 创作仍使用用户配置的接口。

## 验证

- 前端 TypeScript 检查与演示构建。
- 手机和电脑浏览器检查回放最终文字与第一章全文相同，包括原第 1200 字符位置之后的内容和最后一段；验证进度、结束提示、全文展开收起、重复回放，以及回放期间作品数据不被修改。
- 保留工作区其他已有修改，只提交本次修复与更新说明；推送后通过现有 GitHub Pages 工作流发布。

浏览器回归脚本为 `packages/frontend/tests/demoPlayback.browser.cjs`，在演示构建预览后通过 `node packages/frontend/tests/demoPlayback.browser.cjs` 运行。环境需已有 Playwright，也可用 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH` 指定已有安装；`DEMO_URL` 可切换为线上演示地址。脚本在独立浏览器上下文中检查第一章全部 6703 个字符、全文显示切换、重复回放和数据不被覆盖。
