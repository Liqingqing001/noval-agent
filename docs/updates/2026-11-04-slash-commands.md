# 斜杠命令与命令菜单

在 AI 助手输入 `/`，或点输入框旁的命令按钮，可查看、搜索和补全命令。英文命令与中文别名共用注册表，菜单显示用途、参数、示例，以及「本地」或「AI · 可能计费」。选择只补全文字，不执行操作；补充参数后再发送。

电脑可用上下键选择、Enter / Tab 补全、Esc 关闭；手机支持点选、列表滚动，回车仍用于换行。中文输入法确认候选字时不补全或发送。已有普通草稿会保留在 AI 命令参数中；本地命令不会通过菜单覆盖普通草稿。

Pages 未配置模型时，示例回放底部的「本地命令与对话」会打开同一个对话组件，本地命令可直接使用；「返回示例回放」保留原有演示入口。AI 创作仍需配置自己的模型。

## 本地命令

| 命令 | 用途 |
| --- | --- |
| `/help`、`/help continue` | 查看全部帮助或指定命令用法 |
| `/status` | 查看模型、会话和上下文状态 |
| `/context` | 查看实际或预计带入的章节与历史范围 |
| `/usage` | 打开调用记录与预算 |
| `/compact`、`/compact 12` | 精简后续请求的历史；条数可设为 2–30，原记录不删除 |
| `/compact off` | 恢复常规历史范围 |
| `/export` | 导出当前完整会话为文本 |
| `/clear` | 确认后清空当前会话，不删除作品资料 |
| `/history` | 打开章节版本历史 |
| `/timeline 林夏` | 打开人物状态时间线，可用完整姓名或已有别名；省略人物则打开面板 |
| `/review` | 打开全书一致性检查，不自动开始 AI 审读 |
| `/prompt` | 打开本书自定义提示词编辑框 |
| `/stop` | 停止正在生成的任务，保留已收到的文字 |

支持 `/帮助`、`/状态`、`/上下文`、`/预算`、`/历史`、`/时间线`、`/全书检查`、`/停止` 等中文别名。生成中可使用帮助、状态、上下文、预算和停止命令；其他命令会明确提示先结束当前生成。停止请求不代表服务商一定停止计费，实际用量以调用记录和服务商账单为准。

## AI 创作命令

| 示例 | 行为 |
| --- | --- |
| `/outline 校园规则怪谈，五卷群像` | 按需求生成大纲 |
| `/outline 优化 增加配角线` | 优化已有大纲 |
| `/continue 当前 2000字` | 在当前正文后追加续写，保留已有文字 |
| `/continue 下一章 3000-4000字` | 按全书进度与大纲继续下一章 |
| `/continue 三章 1500字` | 按大纲继续三章，每章使用指定篇幅 |
| `/check 当前`、`/check 最近5章`、`/check 1-3` | 只审读并提供建议，不写回正文 |
| `/polish 对话更自然，保留情节和人称` | 以准确原文定位，局部润色当前章 |
| `/rewrite 改成第一人称，保留结尾线索` | 确认目标章节后重写当前章 |

中文别名如 `/续写`、`/大纲`、`/检查`、`/润色`、`/重写` 同样可用。明确要求「只讨论」「不要修改正文」时，润色和重写会转成只读建议。

AI 命令共用既有上下文选择、模型协议、预算与重试流程。对话保留原命令及展开后的需求，模型只收到明确的创作要求；本地命令和参数错误不作为模型指令发送。错误或缺失参数会显示用法并保留输入，不自动纠正为可能收费或删除内容的操作。

## 写入与重试

当前章续写、润色和重写会核对目标章节及其发送时的原文，应用前先刷新编辑器。响应包含其他章节、人物、世界观或删除指令，格式不完整，或等待期间原文有改动时，不会部分写入，结果仍留在对话中供核对。合法改稿通过原有章节保存流程写入，并保留改稿前版本。

只读检查即便返回写入标签，也不能同步到作品。重试保留原命令、只读策略和原目标章节；章节已不存在时停止，重写仍需确认目标。新尝试独立计入调用记录，不自动重试付费请求。

## 验证

```sh
npm run test:slash
npm run test:slash-browser
```

测试使用本地模拟模型，覆盖菜单、参数边界、中文输入、草稿保留、离线命令、预算、停止与重试、只读检查及章节写入范围，并回归普通应用、Pages 和手机布局。
