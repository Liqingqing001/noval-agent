# 设置内新增小说创作教程

## 内容与位置

在「设置 → 模型设置」顶部新增「使用教程：离线 / 在线，从零创作一本小说」。使用原生展开文字呈现，正文为一段连贯教程，不增加弹窗、引导向导或额外配置步骤；默认收起，避免长文字影响填写模型配置。

教程覆盖：

- 离线手动编辑与在线 AI 创作的区别；明确网页首次打开或刷新仍需联网，示例回放不是真实生成。
- 从书架新建小说，到填写基本信息、人物、世界观、卷与章节大纲、伏笔，再到创建章节的完整流程。
- 接口协议、地址、认证、模型 ID、测试连接及保存启用，浏览器跨域和本机模型服务的使用前提。
- 当前统一创作助手的使用方式、可直接参考的构思和写章指令、快捷操作、自定义提示词、字数与输出预算。
- 回复折叠、面板自动同步、失败重试、按原文精确修改、停止生成，以及帮助、状态、对话导出和历史管理命令。
- 编辑保存、排版、整本或单章 TXT / Markdown / Word 导出，以及作品备份与 API Key 保存方式。
- 公开演示与普通应用使用不同保存说明，避免把演示的纯本地存储规则描述成所有部署模式的行为。

## 验证

前端 TypeScript 检查与演示构建；浏览器检查电脑和手机中教程的展开、收起、文字换行，以及阅读教程后原有模型配置仍可正常填写。未发起真实模型调用。
