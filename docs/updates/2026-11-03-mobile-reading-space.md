# 手机书架、大纲与章节的可用空间

## 问题

手机虽然已经单面板显示，书架内部仍保留桌面的大块装饰头部和七行纵向功能菜单，挤压书籍列表。大纲又重复显示书名和长简介；编辑器工具栏换行、纸张装饰和内边距继续占用高度。此前仅检查是否溢出，不能保证实际可读区域。

## 调整

- 手机横幅变成紧凑单行；恢复案例入口保留，保存边界和源码放入可展开「说明」。
- 书架头部收紧，隐藏手机端的英文装饰与蕾丝；七个功能入口改为四列网格，横屏七列，保持全部可访问。
- 书籍区域独立滚动，封面、完整书名、状态、字数及操作按钮可见；短横屏使用更紧凑的卡片。
- 大纲简介默认折叠，保留卷数 / 章节数 / 完成数，支持展开、收起和原有资料编辑。创建、筛选、状态说明与伏笔入口保留。
- 大纲长标题换行，摘要和按钮分别排布，不依赖悬停才能在手机编辑 / 删除；横屏把工具和筛选放同一行。
- 章节目录缩小重复头尾信息；标题完整换行，操作按钮独立一列，不覆盖标题。
- 正文格式工具改为可横向滚动的单行，排版菜单保持固定位置且不受滚动裁切；手机保存状态移至底栏。正文去掉额外纸框、花饰和大空白。
- 规则只作用于窄屏 / 短横屏；桌面继续保留原有布局及全部功能。

## 验证

新增 `npm run test:mobile-space`（先构建 Pages 版本）。测试不会写项目数据库，使用隔离的浏览器示例，包含超长简介与标题，检查首本书完整可见、七个功能入口可点击、简介展开收起、章节目录可达第40章、正文首段及末段可读并可滚动。标准除无横向溢出外，还检查各内容区域最低可用高度。
