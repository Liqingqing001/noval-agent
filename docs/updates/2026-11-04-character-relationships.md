# 人物关系画布与档案浏览

人物关系支持全景、单人和两人三个查看范围。选择「聚焦」人物后，再选择「关系对象」，即可只看两个人之间的全部关系；人物详情中也可先点选关联人物，再点「只看这两人」。双向、单向及同一对人物之间的多条关系分别保留。

## 调整关系线

拖动关系线或选中后的移动手柄，可以单独调整这一条线的弯曲位置。鼠标和单指拖动均支持，坐标按画布缩放比例换算；拖线不会移动人物、平移画布或改动其他关系。关系名称仍可点击打开编辑，选中的关系还可恢复自动走线。

单条线的调整保存在当前浏览器，刷新后保留，也包含在「导出人物关系与状态」中。旧版画布没有手工走线数据时继续使用自动走线。

第二根手指加入后，操作转为双指缩放和平移；尚未松手的关系线拖动会取消，避免把一次缩放误保存为改线。手机可使用顶部缩放按钮和「适应画布」，也保留原有双指手势。

## 减少拥挤

全景关系较多时精简关系名称；「更多工具」可以切换名称显示。聚焦视图将相关人物临时排在中心人物周围，两人视图单独排布，便于读清方向和多条关系。「返回全部」恢复进入聚焦前的搜索与画布位置。

聚焦与两人视图的排布、人物拖动仅用于当前查看，不覆盖全景中已保存的人物位置；全景中的人物拖动仍会保存。关系线调整则保存在原关系上，返回全景后仍生效。

## 稳定浏览关联人物

原先点击一条关联人物记录会直接切换整个档案，导致全部关联条目随之改变。现在同一个人的关系按关联对象分组，点击只选择该对象并展开双方关系，当前档案标题、其他关联人物和未保存状态保持不变。

需要换人物时使用明确的「查看某某档案」，并可通过返回按钮回到上一位人物。切换和关闭仍保留未保存状态的确认，真正切换档案后从顶部开始浏览。人物头像预览、档案编辑、状态保存及人物时间线入口保留。
