# 2026-11-02 参考分析格式兼容与响应反馈

用户反馈点击分析后数秒才有反应，并出现「文风卡缺失或过长」。截图表明已有模型返回，错误发生在解析校验阶段；单凭截图不能确定该次原始结果是缺字段、格式不同还是被截断。

## 修复

- 移除点击时对整本书和全部缓存的深拷贝，复用不可变项目快照及已计算的分析计划，减少重复全文解析。先同步显示忙碌状态，再让浏览器绘制一帧后准备模型请求；即使模型首字较慢，用户也能立即看到操作反馈并取消。
- 接入模型服务的连接、等待、推理、流式和非流式阶段，显示已等待秒数与收到的文字量。流式文字展示最多每 100ms 更新一次，结束时补齐，不再每个分片都刷新整个面板。此改动减少页面开销，不保证网络或模型自身首字耗时。
- 文风和方法卡兼容字符串、文字列表、分项对象及明确的字段别名，规范化为可编辑文字；支持最多 20000 字符，不静默截断。限制嵌套深度和项目数，不执行其中标签、代码或指令。
- 真正缺少卡片时保留结构与引文，标记部分报告，禁止用于自动创作；不再将所有问题混称为「缺失或过长」。重新分析失败或返回不完整时，不覆盖此前有效报告。
- 新增「重新解析保留结果（不调用模型）」：对完整 JSON 重新校验当前范围、覆盖与原文短引文；通过后恢复卡片，不产生新请求。残缺 JSON、缺字段或无法覆盖当前范围的结果仍拒绝恢复，不补造结论。恢复后查看报告也不会隐式重发模型；主动重新分析才会调用服务。
- 提示词先要求输出文风与方法卡，并给出明确 JSON 类型示例和简洁长度建议；逐段手法避免冗长复述，降低后续字段缺失或截断风险。明确区分作者、分类、字数、标签等元数据与正文风格，不据此臆测整书结论。

## 验证

参考模块 19 项单元测试，加原有 79 项，共 98 项。完整应用和 Pages 共用的手机、桌面回归增加：对象卡旧结果的免费恢复、查看不产生新请求、缺卡不覆盖有效报告，以及点击同一事件内即可观察到准备状态和取消入口；继续覆盖长文、续跑、迁移与存储失败恢复。

测试模型均为模拟接口，未使用用户密钥或产生真实模型费用。解析兼容不代表文学解读必然准确；分析仍只覆盖所选范围，引文核验只证明位置对应，不证明模型解释正确。
