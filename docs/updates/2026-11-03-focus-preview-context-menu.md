# 人物聚焦、图片预览与右键菜单

关系多时可以只看一人的直接关系。书封和人物头像支持放大；书籍卡片移除底部整排操作，改为右上角的“更多”。普通应用与 Pages 使用同一组组件。

## 只看一个人的关系

在人物关系画布上方的“聚焦人物”选择姓名，或右键人物、选择“聚焦此人”。手机也可通过下拉框选择，或打开人物详情后的“更多操作”。

聚焦后只显示此人、与其直接相连的人和这些连线；相关人物彼此之间的其他连线暂时隐藏。顶部说明当前人物、人数与关系数量。“返回全部关系”恢复之前的缩放、位置与搜索条件。聚焦是查看方式，不自动改写保存的人物位置或关系；没有关系的人仍可单独查看。

手机上图形缩小后，可点击“查看关系清单”，按相关人物逐组阅读关系名称、方向与说明，字号不随画布缩放；头像也可从清单放大。关闭清单后仍停留在当前聚焦人物。

## 图片预览与书籍操作

- 点击书封放大预览，点击书名或卡片空白处进入作品，避免预览时切错书。
- 人物列表、人物编辑器及画布详情中的头像可点击预览；画布节点右键也能选择“预览人物头像”。预览仅显示该人物的头像，不展示整张多人头像图集。
- 图片适应屏幕，支持关闭按钮、Escape 和点击遮罩关闭，关闭后返回原来的操作位置。加载失败时显示提示。
- 书籍右上角“更多”包含预览、更换或添加封面、移除封面、重命名与删除。原来的功能均保留；移除封面、删除作品仍要求确认。新增作品仍使用书架顶部的加号。
- 封面移除以空字符串发送给 API，确保普通应用重新登录后也能保留移除结果。

## 右键、键盘与选字

书籍、画布人物和章节目录支持对象右键菜单。键盘聚焦对象后按 Shift+F10 或菜单键也能打开；方向键切换选项，Home/End 到首尾，Escape 退出。菜单位置限制在屏幕内，点击外部或滚动离开时关闭。手机继续使用可见的“更多”、人物聚焦框和章节操作入口。

卡片、导航、画布、工具栏等操作区域避免误选文字。正文、人物资料、世界观、输入框和文本框仍能选字与复制；编辑区域保留浏览器原生右键菜单。没有全局禁用选字或浏览器右键。

## 验证

`npm run test:interactions` 覆盖普通应用与 Pages 的手机、桌面操作：菜单键盘/右键/触摸入口、边界定位、书封及单人物预览、关闭焦点、封面与书籍操作保留、聚焦过滤及返回、查看不改写正文或布局、正文和输入框可选字。画布单元测试检查直接关系筛选与孤立人物；既有画布、书籍、移动阅读空间和发布中心回归继续执行。

本地普通应用与 Pages 构建、9 项画布单测及两版交互回归已通过。交互覆盖 390px、1680px，以及 320×568 菜单/图片边界；关系清单验证多条关系与说明不丢失、字号至少 14px、关闭后保留聚焦和原图。两本完整案例、既有创作功能、参考创作、人物画布、发布中心与五组移动阅读空间回归均通过；实际新书林夏的六位相关人物、七条关系也完成手机和桌面视觉检查。
