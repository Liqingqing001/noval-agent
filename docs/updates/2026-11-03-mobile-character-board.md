# 手机版人物页与双指画布

修正手机版人物关系页的两个问题：工具栏被长说明和内部滚动挤占、画布只有单指处理因而不能双指缩放。普通应用与 Pages 共用同一个人物组件。

## 手机排布

搜索、人物聚焦、缩放与适应画布保持直接可用，工具栏采用紧凑排布。次要操作和完整使用说明放入“更多工具”，默认收起；不再用可滚动的大段说明占据画布上方。人物新增、关系新增、自动排布、导出、展开画布、聚焦清单及返回总览等能力继续保留。

## 手势

- 单指拖动空白处平移，拖动人物调整位置。
- 两指张开或捏合缩放画布，也可同时移动双指来平移；缩放围绕两指中点，避免突然跳到别处。
- 第二根手指加入时结束单指拖动预览、取消待触发的点按或连线，避免缩放时误移人物或打开关系编辑。
- 缩放后剩余的一根手指不会立即变成人物拖动，全部手指抬起后可以重新单指操作；取消手势也不会保存未完成的拖动。
- 鼠标拖动、滚轮、加减按钮、人物点按连线与双击详情继续保留。手势只作用于画布，不全局禁止页面缩放。

## 验证

`npm run test:board` 包含缩放几何测试；`npm run test:mobile-board` 使用 Chromium 的真实多点触摸输入，覆盖双指放大/缩小、中点稳定、人物上起手、抬起单指、取消与后续拖动，以及手机人物页布局。既有画布、预览、聚焦、关系清单、书籍及阅读空间回归继续执行。

本地前后端构建、12 项画布/几何单测、普通应用和演示版的原生触摸测试均通过。手机尺寸覆盖 320×568、390×844、844×390；演示版对应画布高度为 242、518、143px，工具栏高度为 127、127、77px。多点输入确认缩放围绕双指中点、页面缩放比例不变，不误改人物、连线或打开编辑器。既有画布与工作区交互两版回归、双书 390/1680px 检查和五组阅读空间检查均通过；另目视检查了新书十二人物页面。
