# 2026-11-01 参考文章分析与辅助创作

本次完成用户确认的文章首版：从参考文章导入、结构与文风分析，到换主题拟提纲、写新稿、编辑导出及确认导入小说。完整范围与使用步骤见 [实施 PRD](../prd/reference-article-mvp.md)。

## 更新内容

- 书架新增「参考创作」，无需选书即可进入；手机和桌面共用实现，工作台内隐藏普通小说助手。
- 支持粘贴、TXT、Markdown，兼容常见 Windows 中文编码，保存前预览，超限明确拒绝。
- 按段统计与分析，短引文核对原文并可定位，报告与卡片可独立导出；无完整覆盖或可核验依据时不进入自动创作。
- 提供可编辑文风和结构卡、新主题简报、可编辑提纲和明确确认，随后生成独立新稿；改动要求后使原确认失效。
- 显示实际非空白字符数、完成情况、占位内容和当前参考文的连续字面重合，支持人工修订确认。
- 新稿导出 TXT / Markdown / Word，复用现有宋体、黑体中文导出排版。
- 预览确认后仅新增章节，同名冲突不覆盖，同一版本重复操作不重复新增；参考原文及标签不会自动写入人物、世界观或正文。
- 本地保存按环境和用户分区，存储失败不冒充已保存；请求失败或取消保留部分输出和原有有效稿。
- 设置教程加入参考创作完整用法；CI 增加文章模块单元测试及完整版 / Pages 同流程浏览器回归。

## 验证与限制

新增 9 项单元测试，与原有 79 项测试共 88 项通过。前后端完整版构建、Pages 构建通过；两种构建均在手机 390px、桌面 1680px 验证文章闭环。所有模型测试使用模拟接口，真实服务商的内容质量、额度和跨域可用性仍取决于用户配置。

参考资料和独立新稿只保存在本浏览器，未增加云端参考数据库或后台任务；本次无需迁移数据库。长书、DOCX/PDF 输入和跨设备同步暂缓。既有主包体积超过 500 kB 的构建提示仍存在，新工作台单独懒加载。

Word 导出的新稿和分析报告样本均用本机 Microsoft Word 只读打开并转为 PDF，各 1 页；随后渲染成页面图片逐页检查，未见乱码、缺字、文字重叠或裁切。检查 OOXML 确认正文宋体、标题黑体、西文 Times New Roman，无冲突的主题字体引用和固定行高。该验证针对本次样本，不代表任意用户输入都经过人工逐页检查。生成内容不保证自动达到文学质量或全网原创，仅提供可检查的草稿与局部重合提示。
