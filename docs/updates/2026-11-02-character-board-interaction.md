# 2026-11-02 人物画布交互与边界修正

根据实际使用反馈调整人物画布，普通应用与 Pages 共用实现。

- 单击人物选择箭头起点，显示高亮与虚线预览；再单击另一人物打开关系表单，填写名称后保存。原有「添加关系」按钮保留。
- 双击人物才打开人物详情；手机使用连续点按两下。点击空白、再次单击起点或按 Esc 取消连线，双击不留下待创建关系。键盘 Enter 查看详情、空格选择连线，方向键继续移动人物。
- 移除打开人物面板时的自动平移，打开、关闭及切换人物详情都保持当前视图。侧栏继续覆盖显示，不挤压或重新定位画布。
- 移除人物位置 0–20000 的夹取与读取限制，保留数值有效性检查。旧记录直接兼容，负坐标与远处位置可保存和刷新恢复。
- 取消固定尺寸 SVG 连线范围，允许连线向所有方向延伸；仍可通过「适应画布」找回人物。

验证：画布数据单元测试、完整应用与 Pages 的手机和桌面浏览器回归，覆盖单击建箭头、双击无误连、取消、视图不跳动、跨越旧上边界、负坐标保存刷新及既有状态、头像、导出、人物列表和云端编号衔接。新增数据的本机保存与备份方式不变。
