# AI 调用记录与预算

入口为「设置 → 调用与预算」，AI 助手标题栏也可直接打开。普通应用与 GitHub Pages 共用实现；两种模式各自保存在当前浏览器，不跨设备同步，不向示例作品植入虚构消费记录。

## 调用记录

- 创作对话、快捷创作、参考创作的分析 / 提纲 / 新稿和测试连接统一记录。模型列表查询、示例文字回放、参考创作已完成批次缓存不会产生调用记录。
- 每次调用显示模型、服务商、操作、开始时间、耗时、输出字符、输入 / 输出 / 总 token、状态与费用估算。支持搜索、按状态筛选、分页和 JSON 导出。
- token 优先使用接口返回；缺失部分按文本估算，明确标为「接口返回」「部分估算」「文本估算」。字符数不含空白与隐藏推理，不等于 token 数。
- 对 OpenAI Chat、Responses、Anthropic、Gemini 分别解析用量；累计流事件不重复相加，推理和缓存计数按协议处理。仅对明确支持的 OpenAI / DeepSeek 原生接口自动请求流式用量，兼容网关没有用量时保留估算标识。
- 日志采用固定元数据字段，不保存 API Key、请求头、接口地址、提示词、正文或服务商原始错误。正文和部分结果仍按原有会话 / 参考资料保存方式保留。

## 单价和预算

按服务商、协议、模型和币种填写每百万输入 / 输出 token 的单价。免费模型可明确填 0；没有配置价格显示「未定价」。人民币、美元分别统计，不自动换汇。修改价格仅影响新调用，历史费用保留当时的单价快照。

费用始终是估算，不是服务商账单。当前只计算输入与输出 token 的基础价格，不自动处理缓存折扣、工具收费、网关加价和税费。缺失的用量、服务商隐藏推理与未确认结束的请求可能影响估算，应以服务商账单为准。

预算默认关闭，可选择「提醒」或「拦截」，设置每月预算、单次预算及提醒百分比。请求前按输入与最大输出估算预留，计算其他进行中的请求，结束后结算；拦截在模型请求发出前执行。严格拦截下，缺少价格、输出上限或有无法确定的历史消费时，先要求补齐配置或明确重新开始统计。它不能替代服务商自己的账户限额。

最近 500 条已结束记录保留供查看，进行中的记录另行保留。清空历史和自动淘汰旧记录都不会抹去累计消费；「重新开始统计」是独立的确认操作，仍有执行中的请求时不可执行。本机存储异常时显示提示，并阻止未能保存预留的新请求。

## 失败和重试

AI 助手在生成过程中定期保存已收到的文字，失败、停止或达到输出上限时保留部分结果；未完成内容不自动同步到人物、世界观或章节。刷新后未确认结束的任务标为未完成，不自动重新发送。

「重试本次请求」保留原来的部分结果，重新发送原用户请求，并使用当前作品上下文与模型设置。新尝试独立计次，通过 `retryOf` 关联前一次记录；这是一次可能收费的新请求，不是从服务商流的断点恢复。输入框里尚未发送的草稿不会被重试覆盖。参考创作沿用已有的主动继续与批次缓存，避免重复分析已完成批次。

## 验证

单元测试覆盖消费累计、价格快照、并发预留、预算拦截、存储异常、协议用量、输出保留和重试关联。浏览器测试使用本地模拟模型，在普通应用与 Pages 构建中验证完整操作、手机布局、刷新、导出和隐私字段；测试不调用付费模型。

```sh
npm run test:usage
npm run test:models
npm run test:usage-browser
```
