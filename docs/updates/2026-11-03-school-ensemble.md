# 双书案例：校园规则怪谈与详细人物

保留《潮汐替人记得》，新增《晚自习后，别回头》作为默认打开的完本案例。新书用七名学生连续五夜的经历推进：遇到第八张桌子、验证影子与广播规则、寻找被困同学和旧案原始材料，分组打开消防门并完成撤离。正文四十章、65,013 纯汉字，最后写家属、伤后照护与普通课堂，主线收束。

## 内容与人物

- 新书：七位学生主角、顾敏等五位重要配角，共十二份完整人物资料；每人有头像、外貌、性格、背景、目标、局限、成长及明确关系。
- 原书：保留全部四十章正文，八个人物补充性格、背景、关系与独立头像。
- 两书各五卷、四十张章节大纲卡，全部关联数据库章节；世界观、时间线与已回收伏笔可直接浏览。
- 章节 `title` 仅保存标题。原书旧稿文件中的“第几章”在导入时去除，界面按排序显示一次序号；正文不截断、不改为梗概。
- 新封面、十二人头像图与原书八人头像图为本次 AI 生成，使用 WebP 副本；头像按图集中固定格位显示，不需要外部图片服务。

## 数据与展示

Prisma `Character` 新增可空 `avatar` 与 JSON 字符串 `relationships`。关系记录包含同一本书的目标人物 ID、关系类型、名称、详细说明及方向。后端验证关系对象属于本书；普通应用 API、同步、迁移与前端编辑使用同一字段。数据库中的显式关系用于首次初始化关系画布，已有手动画布位置、连线修改和删除继续保留。

两本在本地项目 SQLite 实际入库，再只查询可公开业务字段，生成 `tideMemory.json`、`schoolNight.json` 与组合 `library.json`。Pages 加载组合快照，默认新书，原书在书架可切换。访客编辑只存在本机；自动增加新书时不会抹去已有改稿、自建作品、对话或 API 设置。“恢复本书案例”只恢复当前示例内容，保留其他书。

```bash
npm run book:build
npm run school:build
npm run db:generate
npx prisma migrate deploy --schema packages/backend/prisma/schema.prisma
npm run demo:import
npm run demo:check
```

`demo:import` 只 upsert 保留的 `case-*` 示例 ID，不 reset、不覆盖其他作品。已有多个账号时通过 `--owner-id` 显式指定，现有示例保留所属账号。SQLite 文件与禁用登录的示例账号不随公开快照发布。

`npm run demo:rebuild` 用临时迁移库重建并校验三个公开快照，适用于 CI；它不会替代本地正式示例库的 `demo:import`。Pages 工作流检查快照与创作源一致，再构建、运行双书和移动端界面回归、部署。
