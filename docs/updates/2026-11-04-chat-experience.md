# AI 对话体验与上下文优化

本次优化保留六个创作快捷操作、斜杠命令、结构化内容同步、失败重试和预算控制，普通应用与 Pages 使用同一套对话组件。

## 带入正确的正文

之前对话固定附加全书最后几章，当前编辑章节只发送标题和字数。现在续写、修改当前章节时带入当前正文及其前文；明确指定章节编号、范围或唯一标题时，按本次需求读取。章节编号与目录显示顺序保持一致，兼容旧数据中的零起始排序。

按照大纲继续下一待写章节与续写当前章节分别处理；「检查章节」保留最近五章的原有能力。本次发送前先刷新编辑器未保存的内容，并从当前作品建立请求快照。

「本次上下文」显示带入的章节、历史条数、估算输入 token 和取舍说明。优先保留本次需求、本书要求及指定正文；参考资料和历史超过输入范围时会明确说明。必须完整读取的正文超限会在发送前停止，整本长文审读可使用「创作检查 → 全书一致性检查」。估算不等于服务商的实际 token 数或上下文容量。

历史消息按条数和输入预算选择，完整聊天记录不因此删除；较长历史的节选会标注未带入内容。帮助、状态等本地命令结果不再作为模型指令发送，失败的半条回复也不会冒充已完成结果。

## 输入与阅读

- 草稿按模式、账号和书籍分别保存，切换或离开前刷新待保存的文字。保存异常时保留输入并显示提示。旧版全局草稿没有可靠归属，需主动恢复到选定书籍。
- 中文输入法确认候选字时，回车不会触发发送；手机回车用于换行，通过发送按钮提交。
- 生成时可继续编辑下一条草稿，发送仍被禁用；本次请求开始或结束不会抹掉后来输入的文字。
- 只有停留在底部时自动跟随回复；上翻后保留阅读位置，通过「回到最新」继续跟随。长回复的折叠预览会展示新收到的尾部。
- 「复制回复」复制完整原始文本。浏览器禁止自动复制时提供可全选的手动复制弹窗，只有真正完成剪贴板写入才显示成功。

## 提示词与历史管理

主提示词移除重复字数施压、固定追问和按阶段一律拒写的规则。用户明确指定的试写、改稿、篇幅和风格优先；章节默认篇幅仅用于没有更具体要求的正文写作。讨论与检查不因出现创作词汇就自动生成写入指令。内容格式、引用原文、完整闭合标签和真实同步结果约束继续保留。

`/compact` 只收紧后续请求携带的历史范围，完整消息仍可查看、复制和导出；`/clear` 在确认后清空当前会话。长久有效的创作要求可保存在本书自定义提示词中。提示词弹窗使用可聚焦、支持 Esc 关闭的对话框。

## 验证

```sh
npm run test:chat
npm run test:chat-browser
```

单元测试与模拟模型浏览器测试覆盖章节定位、长文范围、历史不删除、草稿隔离、中文输入、流式阅读和复制兜底，并回归普通应用、Pages、手机、预算、重试及原有同步流程。测试不调用付费模型。
