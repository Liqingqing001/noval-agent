# 2026-11-02 人物关系画布与状态侧栏

人物模块新增可交互关系画布，原人物列表继续保留。头像节点可以拖动，画布可平移、缩放、适应视野或展开专注模式；点击头像打开人物详情侧栏，编辑档案、头像和当前状态。

关系由用户选择人物后创建，支持文字标签、分类色、方向和备注，点击标签可编辑或删除。原有简介不自动变成关系，避免将模型推测写成事实。手机支持点按和单指拖动，使用加减按钮缩放。

当前状态支持生死、位置、伤势、目标、物品、备注及截至章节。点击保存，或通过应用导航切换功能时提交；没有自动逐章推算，也不自动改正文或注入 AI 历史上下文。原人物档案仍按既有方式保存，新增画布信息只保存在当前浏览器，支持 JSON 导出。

修补人物创建成功后的编号衔接：画布节点、关系、已保存状态和正在编辑的状态草稿随服务器编号迁移。头像只接受本地 PNG / JPEG / WebP，缩小裁剪后存入本机，不请求外部图床。

验证包含原有 98 项和新增 5 项单元测试，共 103 项，以及完整版和 Pages 的手机、桌面画布浏览器回归；同时保留既有创作和参考创作回归。既有主包大于 500 kB 的构建提示仍存在，新画布界面按需加载。

详细范围与限制见 [人物关系画布实施设计](../prd/character-board-v1.md)。本次没有服务器数据库迁移，也未实现云端画布同步、自动关系抽取或按章状态历史。
