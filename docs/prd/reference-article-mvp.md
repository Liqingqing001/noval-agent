# 参考文章分析与辅助创作首版实施范围

日期：2026-11-01。本文记录用户本次确认的范围：优先交付单篇文章的「粘贴 / TXT / Markdown → 分析 → 换主题写作 → 编辑导出」闭环。它是 [V1.1 总体 PRD](content-analysis-creation-prd.md) 的分阶段实施补充，不代表总体 PRD 的长书、服务端任务和运营体系已经实现；原 Word 评审稿保留。

## 使用流程和交付行为

1. 在书架导航进入「参考创作」。不必选择小说，手机从底部「书架」进入导航；工作台占用主区域，避免旁边的普通小说助手混淆资料归属。
2. 粘贴文章，或读取 TXT、MD、Markdown。显示解码后的全文，检查中文和分段后点击保存。支持 UTF-8、带 BOM 的 UTF-16 和 GB18030；无法识别的编码、二进制伪装文件会报错。
3. 主动点击分析。一次分析发送当前所选文章的全部段落和程序统计值，返回逐段结构、读者判断、文风、方法、局限及短引文。程序校验报告字段、段落编号和短引文是否原样位于指定段落；点击引文可定位原文。覆盖缺失或没有核验成功的依据时保留部分报告，阻止自动创作。引文位置正确不表示模型的解释或事实判断正确。
4. 在「文风与方法卡」编辑通用特征，再到「新主题创作」填写自己的主题、标题、读者、长度和素材要求，选择借鉴文风、结构或两者。生成调用不再携带参考全文，只携带选中的卡片、新简报和必要时的确认提纲。
5. 先生成新提纲，用户可修改并勾选确认，再生成正文。改主题、卡片或提纲会取消旧确认；已有正文标记为基于旧版本，需重新生成或人工修订确认。
6. 在纯文本编辑框修改新稿。长度按非空白 Unicode 字符计，目标范围可设 500–5000；完成标记缺失、超出目标长度、待补充占位或与当前参考文连续相同 30 字符会显示提示。人工确认完成不能跳过长度、占位和字面重合检查；重合检查只针对当前参考文，不等同于全网查重或原创证明。
7. 新稿和报告分别导出 TXT、Markdown、Word。尚未验收的新稿仍可导出留存。Word 沿用统一导出器，正文宋体、标题黑体、西文 Times New Roman，A4 自动行高和稳定段距。
8. 可选「预览导入小说」：选择作品、填写新章标题、查看正文预览，明确确认后新增一章。同名不同内容停止导入；同一版本重复确认不会重复建章，也不覆盖该章后续编辑。仅导入新稿正文，不自动导入原作设定。

## 本次约束

| 项目 | 首版约定 |
| --- | --- |
| 参考范围 | 单篇 100–20000 个非空白 Unicode 字符，最多 80 个非空行段落；拒绝超限，不静默截断 |
| 文件大小 | 最多 2 MiB；大文件需用户先选范围 |
| 存储 | 当前浏览器 localStorage，最多 10 篇、序列化后约 100 万字符；不新增后端数据库表 |
| 归属 | Pages 浏览器空间与完整版分离；完整版按用户 ID 隔离参考资料；均不跨设备同步 |
| 模型 | 复用设置中已启用配置与现有四类协议适配；每阶段主动点击一次调用，无自动重试 |
| 预算 | 展示所选范围、粗略输入量和最大输出参数，估计不代表精确 token 或金额 |
| 复用 | 同内容不重复建资料；原文版本、模型、接口及主要生成参数相同可复用分析，不另行计费 |
| 中止 | 取消、切换功能或关闭页面中止当前调用；服务商是否停止计费由其行为决定 |
| 失败 | 失败的返回文字单独保留；不冒充有效报告或完整新稿，不覆盖已有有效稿；存储失败显示未保存文字供复制 |
| 小说同步 | 原始资料与模型分析不调用小说自动同步解析器；确认导入才调用现有新增章节功能 |

参考数据、报告、草稿、模型 ID 和导入回执保存在参考空间中；API Key 和自定义认证头不复制到该空间。清理浏览器数据会失去本地资料，应及时导出。普通小说的云端保存仍由完整版既有同步流程处理，新增章节提示不声称服务器已经确认。

## 暂缓事项

DOCX/PDF 输入、整书分层分析、服务端队列、断点续跑、跨设备参考资料同步、模型自动续写、自动重试、精确成本账本、多作品融合、全网查重和爆款概率评分不在本次交付范围。长书方案仍以总体 PRD 为规划依据，后续单独设计服务端存储和任务系统。

## 验收依据

新增独立的参考创作单元测试和浏览器回归，使用模拟接口，不使用真实密钥或消耗模型额度。完整版与 Pages 构建运行同一个浏览器脚本，分别检查 390px 和 1680px；涵盖原文隔离、报告核验与定位、缓存复用、卡片编辑、提纲确认失效、正文验收、三种导出、报告导出、同名保护、重复导入、取消/失败保留及刷新恢复。发布流程先验证完整版，再验证 Pages，最后部署。
