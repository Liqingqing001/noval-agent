# 小说发布平台调研与第一版实现边界

核查日期：2026-11-03。公开网页调研，未登录作者账号、未测试实际投稿、未联系商务接口。来源日期与核查日期分别记录；未核实不等于允许或禁止，无法读取全文的搜索摘要不作为完整规则。以下政策可能变更，应以提交时的官方规则、活动与合同为准。

## 当前功能

已实现：平台目录和地区 / 政策筛选、官方入口、逐步流程、证据链接、作品选择、复制书名 / 简介 / 单章、TXT / Markdown / Word、含 AI 使用自述的投稿资料、自托管 HTML 阅读页。文件均在本机生成。

尚未实现：平台账号授权、远端上传、自动建书、审核同步、签约、收益、定时发布。目录中没有平台被标成已接入。公开发布 API 未核实不代表不存在私有、合作或未来接口。

通用导出不代表平台支持直接导入；有 AI 创作工具不代表允许 AI 生成稿；普通发布不等于能签约变现；AO3 的非商业同人归档与 KDP 的自出版、GitHub Pages 的托管属于不同渠道。

## 起点中文网 / 阅文

- 类型：商业网文
- 定位：男频长篇、类型连载；具体题材与签约以平台要求为准
- 入口：https://write.qq.com/portal/login
- 核查日期：2026-11-03

### 投稿路径 / 待核实步骤

1. 注册 / 登录阅文作家专区，按要求完成实名认证。
2. 普通连载：作品管理 → 创建作品 → 选择站点、读者与文体并填资料 → 写新章节 → 提交审核。
3. 编辑内投是另一条路径：在“投稿给编辑”选择编辑、上传材料；仅编辑可见，不是直接公开发布。

文件能力：编辑内投页明确支持 doc / docx / txt（页面列出 6000—10万字）。这不等于普通连载支持整书文件导入。桌面端宣传有草稿书导入，具体格式仍需登录核对。

接口：阅文开放平台有合作方书籍 / 章节读取、订单回传接口；不能拿它当作作者建书 / 发章 API。本次未找到公开作者发布接口文档，需另行合作授权。

### AI 政策

结论标签：有明确限制

- 生成正文：“投稿给编辑”的内投 / 签约页面明确写：拒绝 AI 生成内容，查实无法签约。这是已核实的入口限制，不将它扩大成所有频道每种发布行为的统一结论。
- 辅助：存在妙笔等 AI 工具，但公开证据未给出统一的可签约辅助比例或发布许可；应按具体入口和合同确认。
- 封面 / 插图：公开封面要求强调版权和审核，未核实到单独的 AI 封面允许 / 禁止 / 披露条款。
- 签约 / 变现：内投页明确关联无法签约；普通发布、编辑审核与签约是不同步骤，不因文件上传成功就推定有收益资格。

### 边界

- 编辑内投不直接公开发表；不能把内投的上传格式或政策无限套用到普通连载。
- 首章字数、审稿周期和封面规格可能调整，以当前后台为准；本版不自动判断签约资格。
- 未登录作者后台，未上传稿件或使用合作方密钥。

## Archive of Our Own · AO3

- 类型：非商业同人
- 定位：以同人等 fanworks 为核心，不是商业网文签约渠道
- 入口：https://archiveofourown.org/works/new
- 核查日期：2026-11-03

### 投稿路径 / 待核实步骤

1. 需要 AO3 账号；新用户邀请与等待以官方 Invitations FAQ 为准。
2. 使用 Post New Work，填写 fandom、分级、必要警告、关系 / 角色 / 标签、简介与语言等。
3. 通过网页编辑器填写作品 / 章节并预览，由作者确认 Post；系列、多章与导入工具按当前 FAQ 使用。

文件能力：官方 FAQ 说明可 Import from URL 导入本人或获授权、已在其他站托管的文本作品，并非直接上传任意 Word / TXT，也不能从 AO3 自身导入。本项目尚未接入该导入工具，可先复制正文。

接口：本次尚未核实到可直接接入的公开发布接口；不等于证明平台不存在合作接口。当前没有远端上传适配。

### AI 政策

结论标签：有条件允许

- 生成正文：OTW 官方声明不禁止符合 fanwork 条件的全部或部分 AI 作品；允许并不等于鼓励，也不是所有任意稿件都自动属于存档范围。
- 辅助：需符合相同的内容规则与权利要求；是否有强制 AI 专用标签以当前 FAQ 为准，本次未确认统一强制字段。
- 封面 / 插图：未核实到独立的 AI 封面总许可；图片嵌入、来源权利与内容规则仍适用。
- 签约 / 变现：AO3 是非商业存档，不能用作品收费、商业推广或付费导流；不能将其当作签约变现平台。

### 边界

- 原创作品也需符合 fanwork 的站内范围；不简单等同于只能发布已有 IP 同人，亦不等同于任意商业小说都适用。
- 发布时分级、警告、侵权与非商业规则仍适用；AI 准入不是免责。
- 账号、邀请和稿件编辑由作者在平台完成；本项目不持有 AO3 凭据。
