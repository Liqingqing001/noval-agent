# 第二十三章 风眼里的电话

第二峰前最后一次家属通话安排在上午十一点。

联合值守组不鼓励告别式录音，怕把仍有机会回家的人提前放进纪念里。但每个人都有权联系想联系的人，于是三台公用电话接上备用网，队伍沿博物馆走廊排开。有人说银行卡放哪，有人嘱咐别给孩子吃冷饭，有人接通以后什么也说不出，最后只问了一句吃了没。

林雾排到电话前，不知道该拨给谁。老周就在楼下做检修，母亲没有号码，父亲的墓在早已沉没的旧陵园。她拨了灯铺的旧线，听着铃声在空屋里响，忽然笑了，笑得自己眼里发热。

老周从楼下上来，看她握着电话，慢慢走过去。她没有挂，只把听筒递给他。

“帮我接一下。”

老人走到另一台分机，接起线。电话里，他像十三年来每一个普通傍晚那样说：“灯铺，您找哪位？”

林雾站在相隔十几步的走廊里，回答：“我。晚上可能晚点回来。”

“知道。门不锁死。”

“不是叫你一直等。你该睡就睡。”

电话那头安静一瞬，然后传来一句很轻的“好”。她挂断，心里没有原谅的盛大声音，却多了一点能容纳复杂感情的空处。她可以恨他做过的事，也可以在今天听见一个愿意留门的人，不必强迫自己马上只剩其中一种。

沈砚没有打电话。他拿着沈渡的语音灯，在休息区听了一遍，最后那句买酱油让他笑出声。陆苗问要不要替他去买，他说潮后一起买，家里这几年都用盐凑合，确实不像话。

许照拨给了一个远在北陆的姐姐。两姐妹多年没有好好说话，姐姐一直劝她搬走，她觉得对方是在让她放弃儿子。电话接通，许照先说许安真的死了，随后停很久，再说自己想等潮退以后，带他的名字去看看别的地方。

姐姐没有说早就告诉你，只问要准备几床被。许照回答一床就好，想了想，又说也可能多带一个孩子，先别铺，等她自己决定。

陆苗坐在旁边假装没听，手里把红笔转了三圈，第四圈掉到地上，弯腰去捡时，脸藏在膝盖后很久。

中午，邵临召集最后会议。他提出若第二峰超过上限，保留一组永久核心应急接入，人数最多六名，全部选择已清楚知情的成年人。会议室沉默下来。这一次他没有藏方案，也没有说可以不承认的委婉词，而是将不可逆风险完整列出。

林雾仍然反对把永久接入写成可自动启动的后备。她提出先明确城市愿意放弃哪些设施，再明确哪些高区可以作为暂时滞洪区。如果尚有可牺牲的空房和财产，就不该先把人的退出锁住。

邵临说高区滞洪会造成巨大经济损失，也可能影响潮后居住。罗师傅摊开清单，指出拟牺牲的低区已承担两次泄压，不能每次都让同样的人失去家。第五站住户代表最后同意开放地下花园与空置车库，条件是全过程留档，潮后统一评估，而不是只赔有产权的人。

这项决定艰难得没有任何人感到高尚。代表在签字时手一直抖，低声说自己存了半生买那套房。秦婆婆站在旁边，说会记得，不让他们以后被写成大家都很乐意。

最终，永久接入后备未获通过。会议保留邵临异议，所有人签名承担各自职责。林雾离开时没有胜利感，只觉得真正的公共决定应该就是这样难，谁也不能把难全转给不在场的人。

下午一点十分，第二峰进入近海。天空忽然露出一条亮缝，风短暂地换了方向。孩子们在安置区以为天晴，跑去看，被大人轻声叫回来。母灯白光在亮缝里显得很淡，第一次看起来不像全城唯一可靠的东西。

林雾巡视七站画面，每张脸都普通，有疲惫，有怯意，也有专心。她没有给任何人讲壮烈的话，只在总频道说：“下一轮按名单轮换。退出要报，设备损坏要报。不知道也要报。”

沈砚接着说：“水路组听见了。”

许照说：“医疗组听见了。”

陆苗的声音最后响起：“登记组也听见了。少谁都要找。”

风从海上回来，电话队伍散了，每个人回到自己的位置。没人保证一定回来，可门的方向已经在地图上画得很清楚。
