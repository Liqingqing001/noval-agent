# 第三十四章 判决到来的上午

正式判决在来年春天公布。

季衡因长期违法延长接入、隐瞒死亡与阻碍退出承担刑事责任，初期灾难条件和潮后配合调查列入量刑考虑，不免除责任。老周因参与非法限制与未成年人未经合法授权取忆受到判决，依法履行限制与社区服务，并赔偿相应损失。邵临在新候选程序、资金使用与信息隐瞒中的责任分案处理，已被免职，部分线索继续追查。

判决书很长，没有人会在读完之后立刻好起来。许照划出与儿子有关的三页，放进文件夹，随后照常去面摊。林雾看完属于母亲和自己的部分，坐了很久，发现自己并没有预想的巨大快意，也没有失望。一个需要发生的程序终于发生，不必负责让所有悲伤同时结束。

老周接受安排前来灯铺收个人物品。他在这里住了十三年，能带走的只装两箱，更多工具其实早已属于铺子。他逐件问，林雾逐件确认，避免把过去的资助又变成一笔说不清的情债。

“房租我按新合同付。”她说。

“这间铺子原先就想留给你。”

“那以后另写。今天先把合同做清楚。”

老人点头。他现在终于不再把拒绝好意当作拒绝这个人，也不再把给东西当作减轻愧疚的唯一方法。箱子合上时，他拿出一张自己写的旧食谱，是林汐教他的面汤比例，记得很粗，盐竟没有数字。

林雾接过，看了一会儿，说难怪鱼总咸。他笑了，眼睛湿，却没有接着诉苦。两人之间仍有沉重的事，也能容纳一个不取消那些事的笑。

季衡服刑前获准提交最后一份公共技术说明，说明旧母灯关闭后的维护风险。他要求林雾审校，不写私人信。她逐页核对，发现一处公式错误，按常规退回修改。两周后收到更正版，附一句“已修”，没有借技术联系讨论原谅。

她接受这份边界。一个人不必被她宽恕才能承担他该做的工作，她也不必持续恨着，才能证明母亲受过的伤。

赔偿程序更难。部分家属不接受统一金额，说不能给一条命定价；另一些急需钱治病，不愿为了原则继续等。家属组最初因此争执，许照提出不要要求所有人用相同方式表达尊严。接受赔偿不是承认钱够了，拒绝某项和解也不能影响依法应得的基础支持。

律师将不同权利拆开说明，避免一张总和解书绑住全部未来请求。林雾看见又一份写着“永久放弃其他主张”的模板，要求删除或单独选择。经过多轮争议，协议终于改成分项确认。不是每家都满意，但至少不再需要用一笔急用钱换掉尚未知道的权利。

马顺的儿子用赔偿的一部分成立夜班工人互助账户，另一部分给母亲换住处。他不愿被报道成将悲痛化为力量，说只是因为自己家确实需要房，也知道别家的夜班人还在漏通知。唐音照原话写，编辑担心不够高尚，她说高尚不是采访对象欠报纸的东西。

陆苗在课堂上被老师问，经历这些是否让她更懂得感恩。她想了一会儿，回答会感谢具体帮过自己的人，也会继续问不合理的事。老师没有立刻反驳，课后让她把这句话写到议论文里，补充事例。她回家抱怨，本来只是回答一句，结果又多了八百字作业。

大家都笑。林雾尤其喜欢这种结果：一个沉重故事最后落在一份普通作业上，而不是要求孩子永远站在台上示范如何坚强。

判决后第一个星期五，林雾去给母亲办理迟到的死亡登记。原先的失踪状态撤销，真实时间、地点与原因附有调查文号。窗口人员递来证明，说“节哀”时有些生硬。她接住纸，认真道谢，不因为这份证明迟到很多年，就假装它没有用。

走出大厅，她在台阶上站了一会儿。十三年前，她寻找的是一个还能回家的母亲；今天她带走一张确认死亡的纸。路确实没有通向最初想要的结局，却也没有白走。至少母亲终于不再被登记成一个自己离开、无从追问的人。

天上有两只海鸟，低低掠过第五堤。春潮照常上涨，广播报出高度与误差，后面添了一句：如现场情况不同，请就近报告。林雾听着，慢慢将纸折好。这座城市终于开始允许，眼前看见的事可以比表上的字更重要。
