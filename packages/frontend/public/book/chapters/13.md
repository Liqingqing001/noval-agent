# 第十三章 退潮线之外

海务局允许开放的是第二与第四分闸。第二站在商业街，维护完善；第四站位于高区医院旁，交通方便。两座都不在最容易淹没的地方。季衡解释，这是为了保证试验人员安全，也是因为这两站最有希望通过验证。罗师傅听完，只问：“那低区什么时候轮到？”

邵临没有回答。但潮不会等答案。盐仓门口红线下方已经渗水，比正常涨潮提前了三个小时。秦婆婆拿白灰重新画线，有人问她为什么画得这么低，她说不是线低，是人站得太久，以为水不动。

林雾决定将试验组分开，自己和季衡去第二站，沈砚与罗师傅留守第六站，许照负责医院与疏散接应。陆苗不再只是送信，她和韩禾组织三组路线核查，专门记录轮椅、担架和儿童能不能通过。年轻人嫌她们检查太慢，直到一副担架在楼梯转角卡住，才开始拆拦路的铁架。

疏散比修机器困难得多。许多人不肯走，因为上一次离家以后，房子就被划成了危房，再也没能拿回来。有人担心记忆灯被偷，有人家的老人一出熟悉街道就迷路，还有人养着两只鸡，船上不让带，便索性坐回门槛。

许照在盐仓外立了三张保证纸：临时安置不视为放弃居住权；私人灯可以随身携带；家禽统一托管，登记归还。她没有权限替市政担保第一条，于是把纸送去找街道负责人，站在门口等签名。对方怕担责，拖到天黑，最后在十多名居民和唐音面前签了限期暂保。

“你看，”许照对林雾说，“很多人不是不怕死，是他们已经试过活下来以后什么也没有。”


许照留下的疏散表还有一栏，起初谁都觉得多余：是否有需要一并转移的照护对象。直到一名老人被接到高处，护士发现她不断抓门，追问之下才知道家中还留着一个失能的姐姐。登记员以为“独居”表示没有家人，老人以为“先上车”表示后面会有人去接，两个各自合理的理解之间，差一点漏掉一个不能走路的人。

他们立即派担架组返回。姐姐躺在二楼，床边放好水杯与药，妹妹出门前还替她掖了被角。老人看见人回来，反复说自己没有丢下姐姐。许照握着她的手，回答知道了，接着让登记员把表里的独居改成实际照护关系，不用一个词覆盖整间屋子。

事后复盘时，年轻登记员主动写检讨，第一句是自己不够细心。许照让他先把经过列出来，再看表格、培训与工作量。只写不够细心，下一位累到眼睛发花的人仍会犯同样的错。他们修改问题，要求逐一询问人、宠物、药品和辅助器具，凡无法确认的地方留待核实，不许默认没有。

陆苗看着新表，说原来写不知道也能救人。韩禾点头，把不知道印成正式选项。那三个字占不了多少纸，却给许多原先被催着随便勾选的人留出停顿。林雾将新表带到工程组，发现设备清单同样缺这一项，于是让每站把未经实测的历史数据明确标成未知，不再用空白冒充正常。

这些调整没有漂亮的名字，也没人会在多年后专门记得是哪一张表。但在那晚的安置区，姐妹俩终于在并排的床上睡着，床头分别挂着姓名，不再只有“老人两名”的概括。许照交班前看了一眼，觉得这就足够说明为什么还要多问一次。

林雾在第二站看到完全不同的景象。站内地板干燥，墙上有新漆，七组备用电容贴着本季度检修标签。她照表测试，发现所有数据都漂亮得不像真实设备，稍作追踪，才查出其中一条显示线接的是历史基准，不是实际输入。

值班工程师很年轻，一听就急了，说这么接只是为了让巡检不必每次等潮位变化，实际系统没有问题。季衡问谁允许，他说前任都这么干，主管知道，他们每次都按要求盖合格章。

林雾没有骂他，要求换回实时线，当着他的面重新测。三组电容里有一组衰减严重，若按显示值并联，归潮时极可能先崩。年轻工程师看着纸面，脸一点点白了。

“我要是上报，会停职。”

“你不报，也会有人在错误值上接线。”

他站了很久，最后拿起笔，将自己上月签过的表改成待复核。季衡在旁边加签，不让他一个人承担系统性造假的全部后果。林雾把旧表与新表一起封存，没有允许任何人撕掉旧的。

深夜，第六站传来消息：发现一条仍可使用的旧外海排水道。如果打开，可以将归潮峰值的一部分导入废弃东沉区，为分闸争取三十到五十分钟。问题在于东沉区并非无人，地图上标成废墟，实际住着四百多名拾荒者和无户籍居民。

沈砚的声音隔着线很沉：“可以导潮，但必须先把人带出来。”

“有多少船？”

“能动的三条。估计需要八趟，天亮以后水路不好走。”

林雾抬头看墙上的钟。离十二小时暂停结束还有七个钟点，离归潮首波不到三天。他们不能把人手无限拆开，但也不能把地图上的空白当作真的无人。

她将第二站调试交给季衡，带两个愿意去的搬运工赶往东沉区。临走，年轻工程师追出来，塞给她两块新电池，说按出库流程会慢，他已经记好编号，明天补办。她问他叫什么，他说郑循，循环的循。

“记下来。”林雾对唐音说。

不是为了给他立功，是为了以后每件从仓库里出来的东西都找得到来处，也找得到责任。

东沉区在第七堤外缘，屋子斜插在水里，街灯全靠居民自己接。船到时，一位老妇坐在半淹的阳台上剥豆，听说要撤，先问今天星期几。沈砚回答星期四。她说儿子星期五回来，不能让他找不着门。

林雾看见阳台墙上贴着十几年的日历，每一页都停在星期五。她没有说儿子不会回来，只问能不能先在门上留信。老妇想了想，拿出一张干净纸，让她写：阿妈去高处等你，钥匙在老地方。

写好以后，老妇才上船，怀里抱着没剥完的豆。船离开阳台，她还回头看那张纸，仿佛纸真的能替一间即将沉没的屋子守门。

他们挨家敲门，一扇接一扇。有的人骂，有的人哭，有的人早已收拾好，只差有人肯来。天将亮时，林雾终于看见第七堤的背面。那里布满长年无人修补的裂纹，裂纹中冒出白色盐花，像一整面墙都在慢慢失忆。
