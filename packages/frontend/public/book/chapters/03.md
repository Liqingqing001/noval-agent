# 第三章 无名者的早餐

借河街的人撤离得比林雾想象中安静。卖水老妇把炉灰倒进水沟，挑担工拆下门板，孩子们用绳子互相拴住袖口，仿佛准备去一次不太愉快的郊游。没有人喊，只有鞋底拖过泥水的声音。

沈砚将四本潮位记录分装进防水袋，递给林雾一本：“分开走。我去东梯，你跟卖水的秦婆婆，从洗衣坊上去。”

“我们还没说去哪里。”

“明天五点，南市早餐棚。找一个不给客人加盐的人。”

林雾攥着那册记录跟上秦婆婆。老人步子小，走得却很稳，手推车在窄道每一处转角都恰好擦过去。林雾替她扶车，碰到车底红标小灯。老人立即按住她的手。

“我老伴的。交过税的，别弄坏。”

“没说要查。”

“你们穿蓝工装的都这么说。”

林雾低头看自己的外套，第一次知道这件用来证明手艺的衣服，在另一些人眼里也像制服。她松开手。秦婆婆盯了她片刻，撩开车帘给她看。红标灯的底座被拆过，原本能清楚放出的声音现在只剩一声断续的咳。

“缴税的时候说，拿走一段不重要的。后来他连回家的路都不记得。他自己挑的，签了字。他说年轻时候吃苦的事不留也罢。谁知道回家的路藏在吃苦那几年里。”

记忆不是柜子。拿走一格，旁边的物件不会自动留在原位。林雾在行业规范的第三章读过这种风险，通常写在签字栏下面，字小得需要台灯照着看。她每次给客人解释，客人都点头，说知道了。她也就以为他们真有别的选择。

洗衣坊地板掀开，两个伙计接走手推车。秦婆婆塞给林雾一块粗肥皂：“洗掉裤子上的黑泥。海务局看得出来。”

她回到铺子时已经过了午夜。灯还亮着，老周坐在门后，手里拿她忘在桌上的缴税通知。他没有发火，只问：“画像干了吗？”

林雾站在门口。老人知道她带走了哪张纸，比知道她出门更让人害怕。

“你见过陈望。”她说。

“我跟他年轻时同一个班。”

“母灯班？”

老周低下头，手指来回压那张通知，几次想把它折齐，都没成功。

“你母亲不是死在海上。我知道这么多。”

“你知道了十三年？”

楼下的钟敲了一声。林雾听着自己呼吸，忽然想起十三年来老周做过的所有事：给她交学费，替她找师傅，发烧时把她背去诊所，教她第一道封灯结。那些事像一排突然被海水浸透的木桩，仍在原地，却不知道哪根还撑得住。

“为什么？”

“因为我答应过她照顾你。”

“照顾和替我决定是一回事吗？”

老周抬起头，眼睛里没有她预想的辩解，只有某种用旧了的恐惧。

“那时海务局带你去验亲缘灯。你出来以后，连你母亲的脸都说不清。我把你带回家，你看见灶炉，问第二格怎么没有糖。我就知道他们没取干净。我高兴了整整一夜，也怕了整整一夜。”

林雾想起那场她一直以为是高烧的病。十一岁那年，她在床上躺了九天，醒来后不会系鞋带。老周说是烧坏了短时记忆，慢慢就好。她竟从没问过，为什么一个高烧会留下颈后的细疤。

她抬手去摸，手停在半空。

“所以你替他们看着我。”

“后来我不再交你的记录。每年验灯都用旧样本。陈望替我改过钟。”

“我应该感谢你吗？”

“不应该。”老周说。

这句话让她准备好的愤怒失了落点。她宁愿他解释、狡辩，甚至命令她别再查下去，那样她可以干脆地转身。可他只把铺子钥匙放到桌上，说：“我今晚住楼下。你需要什么就拿。我留着的东西在后院水缸底。”

水缸底有一只防潮铁盒。盒中除了旧工具，还有她母亲的维修笔记。第一页写着潮玻璃清洗比例，最后一页画了一个很奇怪的水轮：七个出水口，七根独立的轴，中央留空。林雾捧着本子，坐在院子里直到天色发白。

她没有原谅老周，也没有把笔记留给他。出门前，她给楼下留了一张纸：我活着。别替我报失踪。

南市早餐棚刚架起来。蒸汽沿棚布淌成水珠，卖粥的妇人用勺敲锅，叫醒坐着睡着的搬运工。林雾找了一圈，最后在一家清汤面摊前停下。摊主是个穿灰毛衣的中年女人，正仔细挑掉面上每一粒葱。

“客人不能吃葱？”林雾问。

“我儿子不吃。”

对面的碗没人坐。林雾没再问，买了一碗不加盐的面。

女人抬眼：“太淡。”

“有人让我这么点。”

女人将帘子拉下半幅，指了指灶后小门。沈砚已经坐在里面，额角破了，血结成一条细线。陆苗蹲在旁边，用煮过的棉线缝他帆布衣上的裂口。

“东梯有人等我。”他解释，“不算严重。”

“衣服还是头？”林雾问。

“都。”

中年女人端进来三碗面，另有一小碟咸菜。她姓许，叫许照，曾是市立医院神经科护士，如今在南市经营早餐摊。沈砚喊她许姐，陆苗始终连名带姓地叫，像是在坚持某种平等。

许照看过记录，没有马上表达惊讶。她从灶砖后抽出一本病房日志，翻到缺页处。缺页前的最后一个名字是沈渡，后面写“转中心接入评估”。

“我儿子许安，十三年前也是这张单。”她说，“先说调到特殊病区，后来登记成离城。我不是来帮你们找回死人。我想知道那张单是谁签的。”

林雾拿出母亲笔记。许照翻到水轮图，手停住。

“这个，我在医院墙上见过。”

“什么时候？”

“潮灾前。你母亲来找过住院部主任，站在走廊里跟他吵。她说中心接入会吞掉人，分闸才是路。主任说试过，来不及。”

陆苗忽然从衣领里摸出一枚铜钥匙，放在水轮图中央。钥匙齿的形状和那七根轴一模一样。

“陈望给的，说等会看图的人来了再拿出来。”

“你怎么现在才说？”沈砚问。

“你又不会看。”

许照把最后一碗面推到林雾面前。天已亮，棚外来了第一波上工的人。有人抱怨盐价，有人讨论昨夜借河街被清查，说那些无户籍的人早该搬走。灶后四个人安静地听着，没有一个人的碗里加盐。

许照将钥匙用布包好。“先吃饭。饿着的时候，人容易把希望当证据。”

林雾捧起碗。热汤下去，胃终于不再发抖。她在那一刻明白，这条寻找母亲的路已经多了另外几个人。他们各有一个空碗，各有一张不肯认的通知。她不能再只凭一句声音往前跑。
