# 第三十三章 没有声音的档案室

公共记忆档案室设在旧学校西楼。这里曾是志愿中心，走廊的感谢画拆去，墙上还留着胶痕。许多人反对在这里做档案，认为换个名字也洗不净过去；也有人主张保留原址，让来的人知道门在哪里、当年发生过什么。最后居民议事会决定一层做证据阅览，二层提供家属支持，不做沉浸式灾难展，也不售卖任何纪念灯。

林雾参加开馆前的检查，最先注意到空间里几乎没有声音。工作人员原本设计了按小时循环播放的旧潮声，许照指出来访者可能经历过创伤，不应当进门就被迫重听。音响撤下，改为自主选择耳机，默认关闭。陈列不再把震撼当作理解的唯一入口。

第一批开放的是经过授权的工程文件、会议记录和制度文本。私人病历设独立查询，必须核对权利和范围。七十四个最早接入者的姓名里，五十九家同意公开，九家不愿，六家仍未联系。林雾发现设计员为了排版整齐，想把不同意的九格做成“匿名贡献者”。她要求先别定，逐家询问是否连存在本身也不希望被展示。

最后墙上公开五十九个名字，其他不留虚构的空位，只在说明中写仍有档案受隐私保护。她将设计员初稿中未经授权的匿名标签划掉，在审校记录中说明。知道全部的人也不能因此替所有人决定被观看的方式。

一名来自外城的策展人提出制作林汐的数字讲述模型，把旧声音拼成面向观众的问答。对方认为能让工程史更易理解，也能让女儿再听见母亲完整说话。演示里，模型用温柔语气回答“你后悔吗”，说自己愿意为城市奉献一切。

林雾当场要求停止。

“她没有说过这句。”

“是根据价值观推演，不是原始录音，会标识。”

“标识不代表您可以替她同意十三年的接入。”

策展人有些难堪，说自己只是想让观众有情感连接。林雾没有指责动机，只拒绝授权，并要求工程史中明确区分原文、解释与推测。她宁可观众面对一个无法回答的死者，也不愿母亲再次被整理成最适合公众期待的声音。

争论后来传到报纸，有人说她垄断公共人物，有人支持防止死者被消费。她写了一篇短文，说明林汐的公共工作可以研究、批评与引用，自己的家属身份不应封锁事实；但私人声音和人格仿制需要另行伦理边界，不能把公共贡献当作无限授权。文章没有平息所有意见，却让下一次讨论至少不必从“女儿不愿放手”开始。

档案室开馆第一天，马顺的儿子带来父亲的小账。他只同意公开工时与工资欠款，不公开信。管理员逐项确认，给他副本和撤回流程。他站在柜台前问撤回真的可以吗，管理员现场演示取消一份测试档案，屏幕立即显示不可访问。他这才签字。

陆苗也来了，抱陈望的钟，却不捐。她只是让工作人员扫描信中与工程账有关的部分，其他带回家。有人觉得既然是重要历史物件，应该统一保管，她说留在家里也是保管。林雾支持她，档案室记录原件由本人持有，不再把公共保存理解成只有机构占有才算可靠。

傍晚，一位从北陆来的女人找到父亲姓名。她已经多年以为父亲抛下家人离城，母亲死前都不肯提他。现在文件显示，他被登记为灾难接入者，后来病亡。她在墙前站了一个多小时，没有哭，也没说终于释然，只问能否带一份不含技术细节的证明回去给姐姐。

林雾陪她办理，听她说：“我这些年恨错人了吗？”

她没有回答是或不是，只说当时的信息被隐瞒，她作出的理解来自自己能知道的部分。女人点头，仍然难过。真相不会把所有感情自动重新排列，有些愤怒失去对象以后，也需要时间找到去处。

闭馆时，管理员关灯，一盏一盏确认没有访客滞留。林雾走过原来的活动室，看见门上的锁已改成双向开启，外侧没有单独锁死的功能。这个改动写在建筑验收里，不作为展品，不供人感动。

她摸了一下门把，走出去。档案室没有替任何人说完过去，却给那些被迫孤独保存的记忆一个可以相互验证的地方。对她而言，这已比一间永不停止发声的纪念馆更接近真正的安静。
