# 第二十八章 证词不能替人活

独立调查在归潮后第四十天开庭。

不是审判所有问题的最后一场庭审，而是接入程序与信息隐瞒的首次公开听证。涉事年代长、部门多，证据散落，谁也不能用一张判决纸立刻结束十三年的事。林雾作为家属和技术证人出席，许照负责病历部分，老周与季衡分别提交自己的行为记录。

开庭前，有人给林雾寄来一封匿名信，说若不是季衡当年做决定，她现在早已死在潮里。信纸最后写：做人要懂感恩。她没有扔，编号存档，与另一封称她为救城英雄的信放在一起。两种信都试图让她成为一个方便讲述的人，她如今不再急着接受任何一种。

老周上证人席时，走路仍一瘸一拐。律师问他当年是否受到直接威胁，若有，可能减轻责任。他想了很久，回答没有人拿枪指他，威胁主要来自他相信不服从会让全城死，也来自他怕被别人认定临阵退缩。

“你是否理解拆除退出装置的后果？”

“理解机械后果。假装不理解人的后果。”

旁听席一阵轻微骚动。林雾看着他，想起小时候自己最信任他的手。他会把每颗螺丝拧到刚好，不多不少。原来同一双手可以做出可靠的工具，也可以准确拆掉别人离开的路。技术的认真不能自动代替伦理的判断，这句话她再也不会只当课程最后一章。

季衡接受质询时，没有否认集中接入在当年确实降低了死亡风险。调查员要求他区分当时可知信息与事后判断。他逐一列出：外堤失效、潮峰误判、分站不足、撤离时间估计偏差。随后列出当时就知道的事实：四十八小时承诺、退出装置被取消、身体维持失败后未告知家属、替代项目多年搁置。

“应急可能解释最初决定的背景。”他说，“不能替之后十三年的持续隐瞒签免责。”

邵临的质询更长。他否认以个人意志操纵候选，指出名单来自现行评分标准。律师将标准逐项展示：无监护、低资产、长期医疗依赖、低社会联系。邵临说这是为了减少接入对家庭的冲击。陆苗坐在旁听席，忍不住握紧椅边。

林雾听见调查员问：“减少家庭冲击，是否实际上降低了没有家庭者拒绝的权重？”

邵临沉默很久，承认标准存在结构性偏差，但不承认每个执行者都怀有恶意。没有人要求他承认恶意，责任并不只在恶意存在时才发生。流程会把偏见盖成一排整齐的章，正是因此才需要拆开看。

许照提交病历时，一名辩护人质疑家属情绪影响证词。她没有争辩自己有多冷静，只要求对照原始记录。许安两次唤醒、请求离开、延后转出、感染，时间链完整。她的悲伤可以影响声音，不能因此让纸上日期消失。

轮到林雾，她陈述自己的取忆经历，明确说明部分内容来自回溯片段，不能单独作为定案依据；相互印证的文件、接口伤痕与当事人证词分别列出。她不愿因为自己受过伤，就让别人也接受没有证据的结论。

律师问她是否希望恢复全部被取记忆。她说希望过，现在仍偶尔希望，但当前没有安全可靠技术，不能为弥补旧伤再接受一次不明确的深度干预。

“如果提供风险补偿呢？”

“补偿不能把不知道变成知道。”


调查结束后，一名档案员带来补充证据。那是大潮年七月十九日的码头售票底册，两张北陆船票登记在林汐名下，一张成人，一张儿童。票在开船前退过，退款被划到紧急维修材料账户。档案员问是否公开，可以证明林汐本有离城机会，或许更能突出她的贡献。

林雾看着底册，拒绝把它写成放弃个人幸福的宣传。她说可以作为行程与时间证据公开，必须说明退票原因没有完整记录，不能仅凭后来发生的事倒推她当时全部想法。母亲可能想留下，也可能只想处理完事故再买下一班，她的犹豫不该被历史替她修掉。

档案员认真修改说明。林雾领到副本，纸上金额很小，成人票与儿童票之间画着一道斜线。她用手指沿那道线走过，忽然想起自己小时候总嫌母亲做决定慢。买鞋要试两双，买菜要问价格，连一张船票也要把背面条款读完。那时她以为长大以后就能立即知道该怎么选，现在才明白，慢有时是因为一个人同时看见了许多会受影响的东西。

庭审没有把退票解释成最终答案，文件只列入证据目录。这样的克制让她感激。母亲已经被太多宏大的叙述借走，至少这一张纸上，她仍可以只是一个给自己和孩子买过船票、后来又退掉的女人，不必再从模糊细节里被塑成没有迟疑的雕像。

她把副本寄给北陆的沈砚，说以后自己也许会去，不一定坐同一条航线。信末写，票可以买新的。寄出后，她在窗口旁站了一会儿，觉得那两张早已作废的旧票终于不再只通向一个被取消的下午，也提醒她，尚未发生的行程仍有权由今天的自己安排。

当天听证没有结论，后续还要审计和刑事线索移交。媒体有人失望，标题写“家属仍未得到答案”。林雾读完，给唐音打电话，说她得到了一些答案，也仍有没得到的，不能写成一无所获，更不能写全部解决。

晚上，老周在庭外等她。他问她愿不愿一起吃饭，她说今天想一个人。他点头，把本来带给她的饭盒拿回去，没有装作不难过，也没有让难过成为她必须答应的理由。

她独自走到南门码头。船票售卖处重开，墙上贴着北陆航线。她站了很久，没有买。此刻留下，是因为她还有事要做，不再因为母亲被困在这座城市里等她。

夜风吹过，码头灯的光落在水面，晃成一段段不连贯的句子。她第一次没有想将它们修复完整。证词能帮助人知道发生过什么，却不能替人活接下来的日子。那部分没有标准答案，只能由她自己慢慢写。
