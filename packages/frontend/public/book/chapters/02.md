# 第二章 借来的河道

检修门外的人没有急着进来。他们将某种金属件逐个敲在门边，轻微的震颤沿管壁传到林雾指尖。她在学徒时见过这种仪器，能听见两道墙后记忆灯的共振。海务局叫它寻灯锤，街上的人有另一个名字：敲门鬼。

沈砚将一根细绳套在她腰上，指向脚下。积水里藏着一条半开的泄压口，宽得只能让人侧身通过。林雾抓住他的衣袖，摇头。她不会游泳。沈砚摊开手，慢慢做了两个动作：闭气，跟绳。他没有把她推下去，只等着。

门外传来年长查灯员的声音：“闸底有灯。开门。”

林雾抓紧绳，钻入水中。咸水立刻涌进鼻腔，冷得像一口从身体里往外张开的井。黑暗没有边，只有前方绳结一次次撞上手掌。她以为自己走了很远，实际上不到十五步，就被沈砚托出另一端水面。她趴在锈梯上咳嗽，胃里翻出下午那只馄饨的味道。

他们上到一条干涸的旧河道。头顶铺满房屋地基和粗细不一的管子，远处有人点着煤油灯卖热水。灯下是一辆手推车，价牌上写“一杯两角，自带杯一角”。沈砚买了两杯，先让卖水的老妇喝了一口自己的，再把另一杯递给林雾。

“怕有毒？”她问。

“怕她兑海水。这边淡水贵。”

老妇踢了他一下：“上个月的账还没还，少败坏我的生意。”

他们坐在旧河阶上。林雾的裤腿不停滴水，画像贴在胸口，纸已经潮了。沈砚看了一眼，递来一块干布，没有伸手替她擦。

“我没见过你母亲本人。”他说，“那句话是陈望交给我的。他说，只有你会听懂。”

“你刚才说是她托的。”

“是。我怕你不肯进来。”

林雾把水杯放下：“我现在就可以不肯。”

沈砚没有辩解。他用缺指的左手拨开衣领，露出颈侧一枚细窄的白色疤痕。那是深度取忆后的接口，普通税灯不会留下这种痕迹。

“我替海务局做过潜闸工。三年前，一次封闸事故，我的弟弟沈渡失踪。他们给我看一盏灯，里面是他爬出水、被医院接走的记录。后来又给了一张病亡通知。两份记录之间隔了六天。我问那六天去哪了，他们说我受伤，记不清。”

“你真记不清？”

“我记得他把救生绳让给我。我以为只要灯证明他得救了，我记错也没关系。”

他说到这里停下，喝掉已经凉透的水。

“去年我在东沉区听见弟弟敲管子。他小时候怕黑，会敲三短一长。我循着声音进去，发现那下面不是水库，是一排接一排的灯。每一盏都有人名，每一盏都还在用电。”

林雾想起母亲失踪那年，家里电灯连续七夜没有熄灭。邻居以为她害怕，替她交了一笔电费。后来账单寄来，写的却是“接入补偿”。老周解释说那是海务局对失踪家属的安置。她接受了，因为十一岁的她需要一个能继续住下去的理由。

河道尽头传来脚步，卖水老妇立刻掀起车底，塞进去一只带红色标记的小灯。过来的是两个挑担工，抬着笼子，笼内不是鸡，是装满记忆灯的木箱。他们朝沈砚点了点头，没有问林雾是谁。

“这里叫借河街。”沈砚说，“地面建城时把旧河封了，没房子的人就借它住。地图上没有，所以水税也不知道该交给谁。大家轮流清淤，雨季轮流守口。你看那条红线，水到那里就要撤。”

他指向墙壁。红线之上还有五六道浅痕，每一道旁边都写着年份。有一条被人画成花茎，顶端用白灰点了一朵花。

“什么花？”

“有人说是向日葵。画的人没见过，按奶奶记得的样子画的。”

林雾突然意识到，在她熟悉的生活下面，竟一直躺着另一座城市。她修过无数穷人的灯，听过他们交不出税、离开旧居、与孩子争吵，却从来没问过灯里的水声究竟来自哪里。那些被归为环境杂音的东西，是他们每天经过的家门。

沈砚带她去陈望的临时住处。那是一间旧泵房，门口挂着停走的钟，钟下放着两把椅子，其中一把腿短，垫着四本账册。室内有一张窄床、一套测绘工具和半面贴满纸条的墙。林雾在纸条里找到母亲的名字，旁边写“七号频段，归潮备用”。下方另有一行：活体接入不等于活人留存。

她盯着那句话，读了很多遍。

“你知道这是什么意思？”

沈砚摇头：“陈望怕我冲动，关键的东西没告诉我。他说得找一个懂灯、又不会把灯里一切都当真的人。”

她轻轻碰了碰桌上半只烧坏的表。表盘下藏着一枚薄铜片，上面刻满非正常的齿序。这不是钟表零件，是早期母灯用的校准栅。她在师傅留下的旧教程里见过，但那些书的相关页都被墨遮住了。

房门突然被推开。进来一个穿红色旧雨衣的女孩，头发剃得很短，肩上背一只书包。她看见陌生人，立刻把嘴里的话吞回去。

“陆苗。”沈砚介绍，“陈望收养的孩子。”

“没收养。”女孩说，“他没在纸上签字。”

“那也是。”

“不是。”

陆苗从包里取出一个饭盒，放在桌上。饭盒里是一小块鱼，两团冷饭。她把其中一团拨给沈砚，另一团推到空椅子前。然后她站了一会儿，又把鱼夹回去，装进盒子。

“他今天不回来？”

沈砚蹲下，将声音放得很低：“今天不回来了。”

女孩转身去墙边，将那把垫着账册的椅子推进桌底。椅腿刮过地面，响得刺耳。林雾想说些什么，却发现自己学会的安慰全是灯铺里的套话：他留下了好的记忆；他不会真正离开；你以后还会听见他的声音。她第一次觉得这些话也许很残忍。死人不回来，一只灯没资格替他答应。

陆苗指了指林雾胸前湿掉的画像：“你的也死了？”

“我还不知道。”

“那你去查。别坐在这里等别人告诉你。”

她说完便背起包出门。沈砚没有拦，只把自己没动过的饭重新包好，塞进她侧袋。女孩走得很快，背影在低矮河廊里忽明忽暗。

泵房安静下来。林雾翻开垫椅子的账册，发现那并非账，而是四份十三年前的潮位记录。陈望在每次涨潮旁都做了标记。大潮年七月十九日，母亲失踪那天，记录显示风速平稳，潮峰尚在两百里外。真正的大潮来在三天后。

“官方说她死于七月十九日海难。”她慢慢说。

“对。”

“海难发生以前，她就被写进海难名单了。”

沈砚将头灯放到桌中央。白光照着那张纸，日期清楚得令人无法躲开。林雾感到一阵奇怪的轻松。十三年里，她一直怕自己的坚持源于不肯接受现实。现在她终于有了一件与思念无关的东西：一个不能同时成立的时间。

河廊里响起钟声，不知谁敲了三下。沈砚站起来，脸色变了。

“封河了。”他说，“有人在查住户。”

林雾看向门口，那里挂着陈望停走的钟。指针不知什么时候动了一格，停在七点十九分。
