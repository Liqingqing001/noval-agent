# 第七章 名单上的孩子

陆苗不肯相信自己在名单上。

不是因为她相信海务局，而是她觉得自己明明很警觉，怎么还能在不知情时成为别人已经安排好的事。她把副本读了三遍，问登记照片什么时候拍的，问年龄是谁填的，问为什么“无监护关系”会写在她前面，仿佛那比她的名字还重要。

“陈望没签领养，所以我就没有人要？”

沈砚说：“不是这个意思。”

“纸上就是这个意思。”

她背起书包要走，沈砚伸手拦，她一把推开。林雾挡在门边，却没有堵住出口。

“你想去哪，我们陪你去。你不想说，也可以。我只希望你拿上这张名单，知道什么人会来找你。”

陆苗看她一会儿，伸手拿走纸，折得很小，塞进鞋垫下面。

“我回去拿他的钟。”

她说的是陈望门口那只停钟。借河街被封后，住户们住在旧盐仓里，泵房可能很快被拆。四个人决定一起去。许照关了面摊，留下“家中有事”的牌子，走出两条街后又折回来，把给儿子摆的空碗带走了。

盐仓里人很多，潮湿的被子挂满横梁，孩子踩着盐壳发出脆响。秦婆婆正在分热水，她的车被查封了，现在拿一个旧水桶算账。有人围过来问名单是真的假的，林雾先说清楚她知道和不知道的部分：这是中央灯塔持有的候选名单，还不能证明最终接入命令已经执行，但个人并没有签过知情同意。

一个男人大声说：“救城也要有人救吧？不然都死？”

秦婆婆抬起桶：“你去？”

男人说自己上有老下有小。旁边一个抱孩子的女人笑了，笑声很短，像剪断一根线。

陆苗没有争辩。她从鞋里拿出纸，走到他面前，问：“我在这里，你要不要看着我说？”

男人移开目光。人群散开一点，让她从中间走过去。林雾跟在后面，明白名单上的名字一旦长出脸，很多轻易说出口的道理就会显得沉重。

泵房门被撬了，墙上的纸条不见了，桌子翻过来压在床上。陈望的钟落在积水里，玻璃裂了，时针停在七点十九。陆苗蹲下捡钟，把水倒出来，用雨衣一角反复擦，越擦越脏。

沈砚弯腰要帮，她立刻把钟抱到胸前。“我会。”

林雾看见地板有两道很新的划痕，一直延伸到排水沟。陈望平时坐的椅子比沟窄，搬运的人不必拖；只有下方藏了东西的水泥盖才会留下这样的痕迹。她叫沈砚，两人撬开盖板，里面是一只被烧坏一角的纸箱。

纸箱中有七份工程账和一盒未用完的齿轮。第一份账写着东分闸重建项目，拨款年份是大潮后的第三年。后面每年都有同类拨款，最后四年支出流向却变成“中心稳定维护”。附页上盖着现任海务局长邵临的章。

许照把纸摊在窗边：“这不是没钱，是把重建的钱继续投给旧系统。”

“陈望为什么没公开？”沈砚问。

陆苗抱着钟，低声说：“公开过。去年他去过报馆，回来挨了一顿打。后来他写信，每封都有人退回来。他以为只要凑齐账就有人管。”

箱底还有一封没写完的信。开头不是给市政，也不是给报馆，而是写给陆苗：我原先想着，等有一间正式的屋子，再去办那个手续。后来又想，等你不再偷东西，等你上得了学，等我病好。现在知道，很多事不能等到样样像个好时候。

陆苗读到这里，把信折回去，重新打开，又折回去。她没有哭，只问：“他真这么写的？”

林雾点头。

“那他怎么没拿给我看？”

没有人回答。沈砚站到门口，背朝他们，替女孩挡住河廊里来往的目光。

他们走时，带走了钟、信和工程账。陆苗坚持自己搬钟，钟很重，她走一段要停一下。林雾想起她第一次见面说的“没收养”，现在才知道那不是不在乎，而是在替一件没有完成的事预先找一个不疼的说法。

回到盐仓，更多人聚在门口。关于新名单的消息已经传开，但传得很乱：有人说所有无户籍孩子都要被带走，有人说面摊里藏着破坏母灯的歹人。一个曾来林雾铺子修灯的工人认出她，问她是不是要关母灯。

“现在关掉，低区先淹。我们就在低区，你们怎么想的？”

林雾把工程账放到空木箱上，一页页压好，没有立即辩解。她说明母灯里的旧核心已经失效加剧，新增接入不是唯一办法，七个分站具备改造基础，但还需要验证。她说，她母亲在旧系统里死了，她有理由愤怒，却没有权力替眼前的人决定用生命冒险。

“所以我们会先做小型试验，再把结果拿出来。没有通过，不能叫你们信。”

工人看着她，问：“失败呢？”

“承认失败，换路。先撤人。”

许照接过话，提出建立家属登记处，逐一核对名单和签字。秦婆婆拿来她的水账，在背面画了四列：姓名、是否知情、去向、还缺谁。很快有人排到木箱前，一个写字快的姑娘自告奋勇帮忙记，陆苗坐在旁边，把每个人的名字重复一遍。

天黑后，沈砚找到林雾，递给她一份今日通告。海务局宣布归潮防御进入三级状态，禁止传播未经授权的母灯信息，所有分闸设备统一封存。通告下方印着林雾的修复师编号，标注“资格暂停，待查”。

她摸了摸口袋里的证件。这张卡花了她六年才拿到，第一次领证时，老周买了一条鱼，烧得特别咸。她曾以为自己终于有了一件不会被轻易拿走的东西。

陆苗走过来，把陈望那枚铜钥匙塞给她。

“他们说你不能修，不代表你就不会修。”

林雾握住钥匙。盐仓里人们正在念名字，一个接一个，生疏的、常见的、总被写错的名字。她想起那七十四个被白光覆盖的铭牌，第一次觉得，自己也许已经找到一件现在就能做的事。
