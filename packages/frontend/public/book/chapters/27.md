# 第二十七章 毁坏的家不是空地

东沉区在归潮后被地图重新涂成浅蓝。

浅蓝代表临时滞洪与待评估水域。市政测绘员在办公室里改完颜色，现场四百一十七人的居住记录却仍旧夹在临时登记本中。新规划草案将这里列为“原无合法建筑区域”，准备修建景观缓冲带。林雾第一次看到那张图时，指尖立刻冷了。

她知道景观缓冲带在工程上有价值，可以减轻下次潮压；她也知道有价值不等于那些屋子从未有人住过。若把受灾区域称为空地，就连谁应当参与讨论都可以顺手省掉。

盐仓开了第一次居民会议。有人主张原地重建，说离开海边就没法拾荒和捕鱼；有人宁愿去高区临时房，受够每年搬家；还有人想拿补偿去北陆。三种愿望吵得很凶，一名干部试图让大家先选代表统一意见。秦婆婆问，为什么非得统一才能有权利，不能一个方案留几条路？

韩禾把诉求分成三列，分别统计，不用多数决定少数必须搬到哪里。事情立刻复杂了，表格也厚了，却比举一次手更接近人们真正要过的生活。

林雾受邀解释导潮经过。她把排水门开启前后的数据全部带来，承认东沉区承担了保全其他住区的损失。有人问她是不是早就想好牺牲这里，语气很重。沈砚准备解释，她示意不用，让对方说完。

那是阳台剥豆的老妇，姓蔡。她说门上的信没了，儿子回来怎么办。全场安静下来。林雾不能用“他不会回来”结束问题，也不能答应一间已经塌掉的屋子会原样长回去。她提出建立旧址与迁居对照，把所有愿意留下联络的人登记，设在新旧码头都能查询的地方。

蔡婆婆问信还能不能再写。她说可以，一起写。

工程组随后面临真正难题：若完全恢复旧住区，下次归潮仍危险；若保留滞洪，新房建在哪里、资金何来、产权怎么安排。邵临提出以公共租住方式解决，居民担心租金逐年上涨。律师补充长期租约和灾民优先条款，市政财政说预算不够。

于是大家又翻开十三年工程账。部分滞留专项资金可以先用于临时安置，长期部分要由审计与议会重新划拨。这个过程慢得令人恼火，没有任何一次激昂发言能马上让四百多张床出现。林雾每周去两次，能回答的回答，不能回答的写进待办，不再凭着愧疚随口保证。

沈砚带居民回旧区辨认物品。退潮后，许多房屋歪在泥里，进门前必须先做支撑。有人只找一只锅，有人找结婚照片，有人什么都没找，只坐在原门槛的位置抽烟。陆苗跟着做记录，第一次没有催别人快。她知道有些人不是不知道房子塌了，是身体还没学会怎样离开那一块地。

蔡婆婆的豆罐在一堆破瓦里找到，完好无损。罐里豆子发了芽，白嫩细长。她看了很久，说带回去试着种。海城缺土，林雾去博物馆找那盆展品泥土的去向，得知十年前已被一所学校领走，养过薄荷。学校愿意分出一小袋，装在旧饼干盒里送来。

一袋土在城里绕了那么多年，终于装进一个灾民的豆罐。没有人说这是象征，他们只认真讨论盆底要不要打孔，盐水会不会让芽死掉。

一个月后，第一批过渡住房确定在第五堤背风侧。原来的空置仓库改成小型单元，采光差，但给水和通道合格。林雾随居民逐间验收，发现两间门槛仍过高，廖青的轮椅进不去。施工方说其他房都能进，给他换一间就好。廖青摇头，说邻居家也该能去，不能以后每次串门都先问门槛。

门槛最终全部削平。这个改动不大，却让居民会议第一次响起真正轻松的笑。

新房钥匙发放时，每把钥匙附一张旧址卡，不是为了要求人记得苦难，而是让任何后来的规划者都不能再说，那里原来什么也没有。蔡婆婆把旧址卡挂到豆罐旁，给儿子的新信写：阿妈搬家了，这次有人知道我去了哪里。

林雾替她封口，忽然意识到，重建并不是把城市恢复到灾前的样子。灾前也有很多人没有门牌、没有退出、没有被地图看见。若什么都原样修好，他们做过的一切就只剩一场更熟练的防守。
